Claude Vision, Canvas API
Tools
Claude Code, Supabase

Learnings

Favicons are deceptively hard at small sizes. AI generation needs heavy post-processing to look sharp at 16x16. The API mode turned out to be more useful than the GUI — developers want a curl command, not a UI.
