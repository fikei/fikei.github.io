# Taste & Pattern Surfacing

> **Status:** ⚠️ Partial
> **Brand Principle:** Input shapes output
> **Key Personas:** DJ, Sound & Scene Curator, Researcher, Cultural Omnivore

What you experience informs what you create. This feature area makes that connection visible — surfacing patterns, trends, and through-lines across what someone collects.

---

## What's Shipped

### Widget Suggestions
- "Complete the Look" widget analyzes collection gaps and suggests items
- "Gap Filler" identifies missing categories and suggests one item
- AI-generated recommendations based on pin context
- Outfit tier analysis (mainstream, premium, luxury)
- User can provide custom prompts for suggestion context

---

## What's Planned

### Taste Profile
- Auto-generated summary of collection patterns
- Top domains, categories, content types visualized
- "You save a lot of X" surfacing
- Taste evolution over time

### Trend Detection
- Identify emerging themes across recent saves
- "3 brutalist architecture links this week" style notifications
- Weekly/monthly trend reports

### Cross-Category Connections
- Surface related pins across different categories
- "These pins share a theme" connections
- Connection visualization (graph or timeline)

### Monthly Digest Widget
- Auto-generated summary of curation activity
- Highlights: most-saved category, new interests, collection growth
- Shareable digest format

### Collection Timeline
- Visual timeline of saves over time
- Filterable by category, content type, tag
- See density patterns (when you save most, what triggers saving bursts)

## Persona Fit

| Persona | What Surfacing Gives Them |
|---------|--------------------------|
| DJ | See what sounds/labels they've been gravitating toward — informs set direction |

| Researcher | Identify emerging themes before they become obvious — competitive advantage |
