**URL**: [ctrl.rodeo/boards](https://ctrl.rodeo/boards)
**Status**: 🟢 Active Development
**Last Updated**: 2026-02-04

---

## Description

Boards is a link curation application that helps you collect, organize, and share interesting content from the web. It features:

- **Swiss Grid Layout** - Clean, organized visual presentation
- **AI Categorization** - Automatic content type detection and category suggestions
- **Content Enrichment** - Automatic fetching of images, descriptions, and metadata
- **Collaborative Boards** - Share collections with others (in development)
- **Web 1.0 Aesthetic** - Minimal, functional design

## Strategy

### Vision
The ultimate personal curation tool - a place to save, organize, and rediscover everything you find interesting online.

### Target Users
- Digital collectors who save links across many topics
- Fashion enthusiasts curating outfit inspiration
- Researchers organizing resources
- Anyone who wants a better bookmarking experience

### Differentiation
- AI-first approach to organization (vs. manual tagging)
- Beautiful visual presentation (vs. plain bookmark lists)
- Emergent categories (vs. pre-defined folders)

### Success Metrics
- Links saved per user per week
- Return visit rate
- Category accuracy (user corrections)
- Shared board engagement
